# Fitness Management

Fitness Management is a modern web application designed to help users plan workouts, manage fitness activities, and track their exercise progress in one place. The platform provides an intuitive interface for exploring workout routines, creating personalized plans, and maintaining a consistent fitness journey.

## 🚀 Technologies Used

- Next.js
- React
- JavaScript
- Tailwind CSS
- Next.js App Router
- Context API
- REST API
- Git & GitHub

---

## ✨ Features

### 🏋️ Workout Library

- Browse a collection of workout routines.
- View workout images, categories, equipment requirements, duration, calories, and ratings.
- Access detailed information for each workout.

### 📋 Workout Details

- View complete workout information.
- Check descriptions, equipment, difficulty level, sets, reps, duration, and calories.
- Follow step-by-step workout instructions.
- Add workouts to a personal training plan.
- Save workouts for future use.

### 📅 My Plan

- Manage selected workouts in one place.
- Track total workouts, duration, and calories.
- Mark workouts as completed.
- Remove workouts from the plan at any time.

### ❤️ Saved Workouts

- Save favorite workouts for later.
- Quickly access saved workouts.
- Remove saved items when needed.

### 🔔 Notifications

- Instant feedback when workouts are added, saved, removed, or completed.

### 📱 Responsive Design

- Optimized for mobile, tablet, and desktop devices.
- Clean and user-friendly interface built with Tailwind CSS.

### 🔄 Dynamic Routing

- Individual workout details pages using Next.js dynamic routes.
- Fast navigation and seamless user experience.

## 📦 Getting Started

### Clone the Repository

```bash
git clone https://github.com/gazishawon999/fitness-management.git
```

### Navigate to the Project Directory

```bash
cd fitness-management
```

### Install Dependencies

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

You can also use:

```bash
yarn dev
```

```bash
pnpm dev
```

```bash
bun dev
```

### Open in Browser

```text
http://localhost:3000
```
